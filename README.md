# dossier – портфолио-сайт как node-graph

Сайт: **[dossier.zive26.ru](https://dossier.zive26.ru)**

Портфолио Анастасии Чернова (автоматизация / n8n-разработка / Technical PM / AI-LLM Integration), сделанное не как обычный лендинг с резюме, а как рабочий канвас в духе n8n – с нодами-кейсами, попапами в стиле открытой ноды и переключателем ролей.

## Что здесь есть

- **Граф опыта** – каждый кейс представлен как компактная нода (квадратная плитка + подпись, как в n8n), а не карточкой с текстом. Клик открывает попап в виде «открытой ноды»: шапка с иконкой, вкладки Parameters/Settings, панели Input/Output.
- **Переключатель ролей** – реальная триггер-нода «Кто я?». Три роли (n8n-разработчик / Technical PM / AI-LLM Integration) подсвечивают релевантные кейсы и приглушают остальные. Работает и по клику, и напрямую по ссылке (`?role=n8n`, `?role=pm`, `?role=ai`) – удобно рассылать разные версии сайта под разные версии резюме.
- **AI-чат-виджет** – отвечает на вопросы о стеке и опыте: сначала быстрый ответ по заготовленным FAQ, LLM (Claude Haiku) подключается только когда вопрос выходит за рамки FAQ.
- **Живой счётчик** – в одном из кейсов (pet-проект по автопоиску работы) число обработанных вакансий подтягивается из реального n8n-воркфлоу через вебхук, а не захардкожено.
- Полностью адаптивно – отдельная раскладка графа для десктопа, планшета и мобильного.

## Стек

- Чистый HTML/CSS/JS, без фреймворков и шага сборки
- Бэкенд для чата и счётчика – n8n + Claude Haiku API
- Деплой – Docker (nginx) через Dokploy, за Traefik

## Структура

```
index.html          – разметка страницы, кейсы, чат-виджет
css/tokens.css       – цветовые/размерные переменные
css/main.css         – стили сайта и графа
css/chat-widget.css  – стили чат-виджета (переиспользуемый, портативный)
js/graph.js          – данные кейсов, рендер графа, попапы, переключение ролей
images/              – иллюстрации, диаграммы, скриншоты кейсов
```

## Локальный запуск

Сборка не нужна – это статические файлы:

```
python -m http.server 8080
```

и открыть `http://localhost:8080`.
